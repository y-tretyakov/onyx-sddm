# sddm-theme

Expert skill for building, debugging and packaging **SDDM greeter themes** (Qt6/QML).

## When to use

- Writing or fixing `Main.qml` / theme components that talk to SDDM
- `theme.conf`, `metadata.desktop`, install/uninstall scripts
- Wayland (weston kiosk) vs X11 greeter behaviour
- `sddm` object, `userModel`, `sessionModel`, fingerprint shim
- Black screen, missing cursor, dead clicks, packaging for Arch/CachyOS

## Relation to other skills

| Skill | Role |
|-------|------|
| `qt-qml` | General QML coding rules |
| `qt-qml-test` | Unit tests for components |
