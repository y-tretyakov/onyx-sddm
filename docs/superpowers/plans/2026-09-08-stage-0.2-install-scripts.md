- [ ] **Step 2: Write install.sh**

Write `install.sh`:
```bash
#!/usr/bin/env bash
set -euo pipefail

THEME_NAME="onyx"
SRC_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)/theme/${THEME_NAME}"
DEST="/usr/share/sddm/themes/${THEME_NAME}"

usage() {
    cat <<EOF
Usage: $0 [--dest DIR] [--help]

Installs the Onyx SDDM theme into /usr/share/sddm/themes/onyx.

  --dest DIR   install into DIR instead of /usr/share/sddm/themes
  -h, --help   show this help and exit
EOF
}

while [[ $# -gt 0 ]]; do
    case "$1" in
        --dest) DEST="${2:?--dest requires an argument}"; shift 2 ;;
        -h|--help) usage; exit 0 ;;
        *) echo "error: unknown option: $1" >&2; usage; exit 2 ;;
    esac
done

if [[ ! -d "${SRC_DIR}" ]]; then
    echo "error: theme source not found at ${SRC_DIR}" >&2
    exit 1
fi

mkdir -p "${DEST}"
cp -r "${SRC_DIR}/." "${DEST}/"
echo "installed: ${DEST}"
```
Note: `set -u` + `BASH_SOURCE[0]` — при запуске через `bash install.sh`/`./install.sh` BASH_SOURCE[0] задан. Make executable: `chmod +x install.sh`.

- [ ] **Step 1: Write uninstall.sh**

```bash
#!/usr/bin/env bash
set -euo pipefail

THEME_NAME="onyx"
DEST="/usr/share/sddm/themes/${THEME_NAME}"

usage() {
    cat <<EOF
Usage: $0 [--dest DIR] [--help]

Removes the Onyx SDDM theme from /usr/share/sddm/themes/onyx.

  --dest DIR   remove from DIR instead of /usr/share/sddm/themes
  -h, --help   show this help and exit
EOF
}

while [[ $# -gt 0 ]]; do
    case "$1" in
        --dest) DEST="${2:?--dest requires an argument}"; shift 2 ;;
        -h|--help) usage; exit 0 ;;
        *) echo "error: unknown option: $1" >&2; usage; exit 2 ;;
    esac
done

if [[ ! -d "${DEST}" ]]; then
    echo "not installed: ${DEST}"
    exit 0
fi

rm -rf "${DEST}"
echo "removed: ${DEST}"
```

### Task 3: validate.sh

**Files:**
- Create: `validate.sh`

**Interfaces:**
- Consumes: `--help` соглашение из Tasks 1–2
- Produces: `validate.sh [THEME_DIR]`; exit 0 если все required-файлы есть, exit 1 иначе; дефолт — `theme/onyx` в корне репо

- [ ] **Step 1: Write validate.sh**

Write `validate.sh`:
```bash
#!/usr/bin/env bash
set -euo pipefail

ROOT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
THEME_DIR="${1:-${ROOT_DIR}/theme/onyx}"

usage() {
    cat <<EOF
Usage: $0 [THEME_DIR] [--help]

Validates the Onyx theme file set.

  THEME_DIR  theme directory to check (default: theme/onyx)
  -h, --help  show this help and exit
EOF
}

# Append to validate.sh before required-files check:
case "${1:-}" in
    -h|--help) usage; exit 0 ;;
esac

REQUIRED_FILES=(
    "Main.qml"
    "ThemeState.qml"
    "translations.js"
    "PROVENANCE.txt"
)

status=0
missing=()

for f in "${REQUIRED_FILES[@]}"; do
    if [[ ! -e "${THEME_DIR}/${f}" ]]; then
        missing+=("${f}")
        status=1
    fi
done

if [[ ${status} -eq 0 ]]; then
    echo "OK: ${THEME_DIR}"
    exit 0
fi

echo "FAIL: ${THEME_DIR} missing:" >&2
printf '  - %s\n' "${missing[@]}" >&2
exit 1
```
Make executable: `chmod +x validate.sh`.

- [ ] **Step 2: Syntax check + valid theme**

Run:
```bash

```
Expected: `bash -n OK`, `OK: <abs>/theme/onyx`, exit 0.
