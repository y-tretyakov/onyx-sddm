# Stage 1.1 — Root + scaling + background Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stage 1.1 Phase 1 (MVP) — верифицировать, что root + scaling + background greeter удовлетворяет спека 1.1, при необходимости сделать мелкий polish, поднять версию до `0.1.0-mvp` и закрыть этап.

**Architecture:** Код, требуемый спека 1.1 (`Main.qml` root `Rectangle` + `s = Screen.height/768` + `bgColor`; `ThemeState` как единый источник scale/цвета; `theme.conf` + `metadata.desktop` installable), уже присутствует как побочный результат Phase 0 (stages 0.1/0.3) и был принят в `dev`. Этап 1.1 — **не** «писать с нуля», а **верификация** (preview/greeter без QML-errors, чёрный/цветной full-screen, `validate.sh`, qmllint) + опциональный polish при выявлении косяков + bump версии до `0.1.0-mvp` + синхронизация статусных поверхностей (README, CHANGELOG) + commit/PR/merge.

**Tech Stack:** Qt6 / QML (`import QtQuick` без версии), bash (`validate.sh`), GitHub Actions CI.

**Spec:** `docs/SPECS/00-mvp.md` §Stage 1.1 («Root + Scaling + Background | 0.1.0-mvp») + `docs/ROADMAP.md` §3 Phase 1 stage 1.1 (deliverables: `s` property, full-screen root, bgColor) + `docs/ARCHITECTURE.md` §1.6 (graceful degradation), §4.1 (Main composition-only), §4.3 (ThemeState source of truth), §9 (preview/testing) + `sddm-theme` skill (metadata.desktop / theme.conf / scale / preview без `sddm`).

## Global Constraints

- Трогаем ТОЛЬКО (при необходимости): `theme/onyx/Main.qml`, `theme/onyx/ThemeState.qml`, `README.md`, `CHANGELOG.md`, `docs/superpowers/plans/2026-09-08-stage-1.1-root-scaling-background.md` (этот план), и — только если polish — **новые** `theme/onyx/components/background/*` по явному решению. НЕ трогаем `install.sh`, `uninstall.sh`, `validate.sh` (уже консистентны), `metadata.desktop`, `theme.conf`, `docs/SPECS/**`, `docs/code-reviews/**` (**read-only для оркестратора и субагентов — пишет туда только пользователь**).
- Масштаб по решению пользователя: **только верификация + bump. Никакого нового Background.qml-компонента в этом этапе.**
- `import QtQuick` (Qt6, БЕЗ номера версии) — никаких `QtQuick 2.x`.
- Scale: `s` вычисляется ТОЛЬКО в визуальном root `Main.qml`, `ThemeState` — единый источник значения (ADR F2, уже принято).
- Preview-safe (graceful degradation ARCHITECTURE §1.6): без `sddm`/`config` тема не падает, фон `#000000`.
- Никакого debug-мусора, лишних комментариев, лишних файлов.
- Вся работа — в ветке `stage/1.1-root-scaling-background`, ответвлённой от `dev`.
- Commit messages по конвенции AGENTS.md §3: `stage(1.1): ...`.
- По завершении: bump версии → `0.1.0-mvp` (CHANGELOG новая запись сверху + бейдж/статус в README синхронизированы).
- Этап НЕ закрыт (Definition of Done, AGENTS.md §8) без: выполнения acceptance, приёмки оркестратором, commit в `stage/1.1-...`, PR → merge в `dev`, версии bumped + CHANGELOG обновлён.
