# Stage 1.2 — Digital Clock + Indicator Pill · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a live digital clock (hours in large font) and a minutes/seconds indicator pill to the Onyx greeter, all scaling via `s`.

**Architecture:** Two new QML components (`TimeProvider` for time state, `DigitalClock` for visuals) plus a pill sub-component, wired into `Main.qml`. TimeProvider is a plain QtObject with a 1000 ms Timer; DigitalClock is the visual container (hours text + pill) centered on screen. ThemeState stays unchanged — time is orthogonal to theme config.

**Tech Stack:** Qt6 QML (QtQuick), `qml6`/`qml` for preview, `sddm-greeter-qt6` for real greeter, `validate.sh` + `qmllint` for checks.

**Spec:** `docs/SPECS/00-mvp.md` §1.2 (Digital Clock + Indicator Pill, v0.1.1-mvp)

**Roadmap:** `docs/ROADMAP.md` — Stage 1.2, version `0.1.1-mvp`

## Global Constraints (from SPECS/00-mvp.md §MVP)

- Wayland (Weston kiosk) primary; X11 secondary.
- No i18n yet (hardcoded English / Russian ok).
- No dropdowns, no fingerprint, no complex animations (only base fade-in allowed).

- Scale factor `s = Screen.height / 768` is mandatory — all sizes go through `s`.

## Task 1: TimeProvider — time state (QtObject, no UI)

**Files:**
- Create: `theme/onyx/components/clock/TimeProvider.qml`

**Interfaces:**
- Consumes: nothing (standalone).
- Produces: `curH` (string "00"–"23"), `curM` (string "00"–"59"), `curS` (string "00"–"59"), `curTime` (string "HH:MM"). All readonly.

- [ ] **Step 1: Create TimeProvider.qml**

```qml
import QtQuick

QtObject {
    id: provider

    property string curH: "00"
    property string curM: "00"
    property string curS: "00"
    readonly property string curTime: curH + ":" + curM

    readonly property var _now: new Date()

    function _pad(n) {
        return n < 10 ? "0" + n : "" + n;
    }

    function _update() {
        var d = new Date();
        curH = _pad(d.getHours());
        curM = _pad(d.getMinutes());
        curS = _pad(d.getSeconds());
    }

    Component.onCompleted: _update()

    Timer {
        interval: 1000
        running: true
        repeat: true
        onTriggered: provider._update()
    }
}
```

## Task 2: IndicatorPill — minutes/seconds pill

**Files:**
- Create: `theme/onyx/components/clock/IndicatorPill.qml`

**Interfaces:**
- Consumes: `curM` (string), `curS` (string) — passed from parent.
- Produces: rendered pill at `330*s × 90*s`.

- [ ] **Step 1: Create IndicatorPill.qml**

```qml
import QtQuick

Rectangle {
    id: pill

    required property string curM
    required property string curS
    required property real s

    width: 330 * s
    height: 90 * s
    radius: 12 * s
    color: "#1A1A1A"
    border.color: "#333333"
    border.width: 1 * s

    // Minutes — left half
    Text {
        id: minText

        anchors.left: parent.left
        anchors.leftMargin: 20 * s
        anchors.verticalCenter: parent.verticalCenter

        text: pill.curM
        font.family: "Sans Serif"
        font.pixelSize: 36 * s
        font.weight: Font.DemiBold
        color: "#CCCCCC"
    }

    // Vertical divider
    Rectangle {
        width: 1 * s
        height: 40 * s
        anchors.centerIn: parent
        color: "#444444"
    }

    // Seconds — right half
    Text {
        id: secText

        anchors.right: parent.right
        anchors.rightMargin: 20 * s
        anchors.verticalCenter: parent.verticalCenter

        text: pill.curS
        font.family: "Sans Serif"
        font.pixelSize: 36 * s
        font.weight: Font.DemiBold
        color: "#888888"
    }
}
```

## Task 3: DigitalClock — hours + pill container

**Files:**
- Create: `theme/onyx/components/clock/DigitalClock.qml`

**Interfaces:**
- Consumes: `timeProvider` (TimeProvider instance), `s` (real).
- Produces: centered visual block (hours + pill).

- [ ] **Step 1: Create DigitalClock.qml**

```qml
import QtQuick
import "TimeProvider.qml" as TimeProvider
import "IndicatorPill.qml" as IndicatorPill

Item {
    id: clock

    required property real s
    property alias timeProvider: _time

    width: row.width
    height: row.height

    TimeProvider { id: _time }

    Row {
        id: row

        anchors.centerIn: parent
        spacing: 24 * clock.s

        // Large hour digits
        Text {
            id: hourText

            anchors.baseline: pillItem.baseline
            anchors.baselineOffset: 0

            text: _time.curH
            font.family: "Sans Serif"
            font.pixelSize: 110 * clock.s
            font.weight: Font.Black
            color: "#FFFFFF"
        }

        // Indicator pill
        IndicatorPill {
            id: pillItem

            s: clock.s
            curM: _time.curM
            curS: _time.curS
        }
    }
}
```
