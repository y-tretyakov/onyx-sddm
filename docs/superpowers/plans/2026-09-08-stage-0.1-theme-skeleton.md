# Stage 0.1 — Empty Theme Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать пустой каркас темы `theme/onyx/` (stage 0.1 Phase 0), готовый к наполнению в следующих этапах.

**Architecture:** Создаётся целевая структура из `docs/ARCHITECTURE.md §3` — только тема (без metadata.desktop/theme.conf: они сознательно перенесены в stage 0.3 согласно `docs/ROADMAP.md`). Корень темы — минимальный loadable `Main.qml` + `ThemeState.qml` со scale-фактором `s` (требование MVP Global Constraints: «scale через `s` обязателен с первого коммита»).

**Tech Stack:** Qt6 / QML (skeleton), без внешних зависимостей.

**Spec:** `docs/ROADMAP.md` §3 Phase 0 stage 0.1 («Репозиторий, ARCHITECTURE, ROADMAP, SPECS skeleton | Docs + empty theme skeleton») + `docs/ARCHITECTURE.md` §3 (file structure). Документы уже в `main`/`dev` (bootstrap commit `8e22ea9`).

### Task 2: Stub source files (Main.qml, ThemeState.qml, translations.js)

**Files:**
- Create: `theme/onyx/Main.qml`
- Create: `theme/onyx/ThemeState.qml`
- Create: `theme/onyx/translations.js`

**Interfaces:**
- Consumes: directory tree from Task 1
- Produces: `Main.qml` (root, black full-screen) + `ThemeState.qml` with `readonly property real s: Screen.height / 768` — используется со stage 1.1 (MVP)

- [ ] **Step 1: Write Main.qml**

Write `theme/onyx/Main.qml`:
```qml
import QtQuick 2.0

Rectangle {
    id: root
    width: 800
    height: 600
    color: "#000000"

    Text {
        anchors.centerIn: parent
        color: "#ffffff"
        text: "Onyx"
        font.pixelSize: 32
    }
}
```

- [ ] **Step 2: Write ThemeState.qml**

Write `theme/onyx/ThemeState.qml`:
```qml
import QtQuick 2.0

QtObject {
    id: themeState

    readonly property real s: Screen.height / 768
}
```

- [ ] **Step 3: Write translations.js**

Write `theme/onyx/translations.js`:
```js
.pragma library
```

- [ ] **Step 4: Verify QML syntax with qmllint**

Run:
```bash

```
Expected: exit code 0, no output (no errors/warnings).

- [ ] **Step 5: Commit**
