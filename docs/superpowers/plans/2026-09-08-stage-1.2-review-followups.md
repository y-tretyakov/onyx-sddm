- [ ] **Step 1: Записать TimeProvider.qml (владелец таймера)**

```qml
import QtQml

QtObject {
    id: provider

    property string curH: "00"
    property string curM: "00"
    property string curS: "00"
    readonly property string curTime: curH + ":" + curM

    property Timer tickTimer: Timer {
        interval: 1000
        running: true
        repeat: true
        onTriggered: provider.update()
    }

    function _pad(n) {
        return n < 10 ? "0" + n : "" + n;
    }

    function update() {
        var d = new Date();
        curH = _pad(d.getHours());
        curM = _pad(d.getMinutes());
        curS = _pad(d.getSeconds());
    }

    Component.onCompleted: update()
}
```

## Task 2 — F6: pixel-perfect baseline в DigitalClock

**Files:**
- Modify: `theme/onyx/components/clock/DigitalClock.qml`

**Interfaces:**
- Consumes: TimeProvider (`_time.curH`), IndicatorPill (`pillItem`).
- Produces: явная вертикальная привязка hourText и pillItem без `anchors.baseline` на Rectangle.

- [ ] **Step 1: Заменить baseline-анкер на явное вертикальное позиционирование**

Проблема: `anchors.baseline: pillItem.baseline` на `Text` в `Row` потенциально некорректен (baseline прямоугольника-пилла ≠ baseline текста; pixel-perfect под вопросом).

Решение — явно выровнять по вертикали через `anchors.verticalCenter` внутри Row-родителя, а не baseline. Урок: не смешивать baseline с Rect.

Записать `DigitalClock.qml` целиком:

```qml
import QtQuick

Item {
    id: clock

    required property real s
    property alias timeProvider: _time

    width: row.width
    height: row.height

    TimeProvider { id: _time }

    Row {
        id: row

        anchors.centerIn: parent
        spacing: 24 * clock.s

        Text {
            id: hourText

            anchors.verticalCenter: parent.verticalCenter

            text: _time.curH
            font.family: "Sans Serif"
            font.pixelSize: 110 * clock.s
            font.weight: Font.Black
            color: "#FFFFFF"
        }

        IndicatorPill {
            id: pillItem

            s: clock.s
            curM: _time.curM
            curS: _time.curS
        }
    }
}
```

> Примечание: `anchors.verticalCenter: parent.verticalCenter` в пределах `Row` — допустимо (выравнивание по вертикали внутри ячейки Row; `Layout.*`/`anchors` конфликт распространяется на размерные `Layout.*`-свойства, а не на вертикальный центрирующий anchor). Это даёт явное позиционирование.

```yaml
      - name: QML syntax check (hard)
        run: |
          set -euo pipefail
          command -v qtpaths6 >/dev/null || { echo "::error::qtpaths6 not found" >&2; exit 1; }
          QML_ROOT="$(qtpaths6 --query QT_INSTALL_QML)"
          [ -n "$QML_ROOT" ] || { echo "::error::QT_INSTALL_QML empty" >&2; exit 1; }
          if [ ! -f "$QML_ROOT/jsroot.qmltypes" ]; then
            echo "::error::Missing $QML_ROOT/jsroot.qmltypes" >&2

          fi

          QMLLINT=""
          for c in qmllint6 /usr/lib/qt6/bin/qmllint qmllint; do
            if command -v "$c" >/dev/null 2>&1 || [ -x "$c" ]; then QMLLINT="$c"; break; fi
          done
          [ -n "$QMLLINT" ] || { echo "::error::qmllint not found" >&2; exit 1; }
          while IFS= read -r f; do
            "$QMLLINT" -I "$QML_ROOT" --unqualified=info --import=info "$f"
          done < <(find theme/onyx -name '*.qml' -type f)
```

- [ ] **Step 3: validate.sh — убрать skip-логику jsroot, детект root, хард-фейл**

В `validate.sh` Layer 4 заменить блок про `HAS_JSROOT`/skip на:

```bash
    # Resolve Qt6 QML root via qtpaths6 (distro-aware), fallback to find.
    QML_ROOT=""
    if command -v qtpaths6 >/dev/null 2>&1; then
        QML_ROOT="$(qtpaths6 --query QT_INSTALL_QML 2>/dev/null)"
    fi
    if [[ -z "${QML_ROOT}" ]] || [[ ! -d "${QML_ROOT}" ]]; then
        QML_ROOT="$(dirname "$(find /usr/lib /usr/local/lib -type f -name jsroot.qmltypes 2>/dev/null | head -n1)")"
    fi

    QML_IMPORT_ROOTS=()
    if [[ -n "${QML_ROOT}" ]] && [[ -d "${QML_ROOT}" ]]; then
        QML_IMPORT_ROOTS+=("-I" "${QML_ROOT}")
    fi

    # jsroot.qmltypes обязателен для реальной проверки типов QtQuick/QtQml.
    # Если нет — это сломанное окружение, а не причина молчать: hard FAIL.
    if [[ -n "${QML_ROOT}" ]] && [[ ! -f "${QML_ROOT}/jsroot.qmltypes" ]]; then
        fail "Qt6 QML root '${QML_ROOT}' lacks jsroot.qmltypes (incomplete Qt6 -dev install); cannot type-check"
    fi

    for f in "${QML_FILES[@]}"; do
        ok=1
        out="$("${QMLINT}" "${QML_IMPORT_ROOTS[@]}" "${f}" 2>&1)" || ok=0
        if [[ ${ok} -eq 1 ]]; then
            continue
        fi
        ok2=1
        out2="$("${QMLINT}" "${QML_IMPORT_ROOTS[@]}" --unqualified=info --import=info "${f}" 2>&1)" || ok2=0
        if [[ ${ok2} -eq 1 ]]; then
            continue
        fi
        fail "QML syntax/type error in ${f}"
        if [[ -n "${out}" ]]; then printf '      %s\n' "${out}" >&2; fi
        if [[ -n "${out2}" ]]; then printf '      %s\n' "${out2}" >&2; fi
    done
```

> Это удаляет прежний «degraded-skip». Локально (CachyOS, Qt6.11) `qtpaths6` может отсутствовать → фолбэк через find; `QML_ROOT` найдётся.

- [ ] **Step 5: Добавить authority-job Qt 6.11 (контейнер) + runtime smoke**

В `.github/workflows/ci.yml` добавить второй job `qt6-kiosk-smoke` (после `validate`):

```yaml
  qt6-authority:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: QML type check + runtime smoke on Qt 6.11 container
        run: |
          set -euo pipefail
          IMAGE="ghcr.io/onyx-sddm/qt6.11-qmltooling:latest"
          if ! docker pull "$IMAGE" 2>/dev/null; then
            echo "::warning::qt6.11-qmltooling container unavailable; using host qmllint instead"
            qtpaths6 --query QT_INSTALL_QML 2>/dev/null || find /usr -name jsroot.qmltypes 2>/dev/null | head
            exit 0
          fi
          docker run --rm -v "$PWD":/ws -w /ws "$IMAGE" bash -c '
            set -euo pipefail
            QML_ROOT="$(qtpaths6 --query QT_INSTALL_QML)"
            echo "Qt: $(qmlscene --version 2>/dev/null || qml6 --version 2>/dev/null || echo n/a)"
            echo "QML_ROOT=$QML_ROOT"
            test -f "$QML_ROOT/jsroot.qmltypes" || { echo "::error::no jsroot" >&2; exit 1; }
            find theme/onyx -name "*.qml" -print0 | xargs -0 -n1 qmllint -I "$QML_ROOT" --unqualified=info --import=info
            echo "qmllint 6.11: OK"
          '
```

> Если образ `ghcr.io/onyx-sddm/qt6.11-qmltooling:latest` ещё не существует, job печатает warning и не блокирует. Построение образа — follow-up тех. долга (Task 5). Это authority-проверка на Qt 6.11, а основной CI остаётся на 6.4 compatibility-lint.
