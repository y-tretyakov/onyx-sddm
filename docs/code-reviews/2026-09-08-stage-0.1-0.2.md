## Issues & Follow-ups

### F1 — HIGH · Main.qml не full-screen и не SDDM-ready

**Сейчас:**
```qml
import QtQuick 2.0

Rectangle {
    id: root
    width: 800
    height: 600
    color: "#000000"
    ...
}
```

**Проблемы:**
- Фиксированные 800×600 — в реальном greeter тема должна занимать `Screen.width` × `Screen.height`.
- `import QtQuick 2.0` — для Qt6 greeter (`sddm-greeter-qt6`) лучше `import QtQuick` (без версии) или явный Qt 6.x стиль, как в ARCHITECTURE / sddm-theme skill.

**Follow-up (сделать в 0.3 или отдельным мелким stage):**
```qml
import QtQuick

Rectangle {
    id: root
    width: Screen.width
    height: Screen.height
    color: "#000000"
    // ...
}
```
И сразу прокинуть `ThemeState` (хотя бы как child / property), чтобы skeleton уже «собирал» композицию.

---

### F2 — HIGH · ThemeState.qml: `Screen` без гарантии контекста

```qml
import QtQuick 2.0

QtObject {
    id: themeState
    readonly property real s: Screen.height / 768
}
```

`Screen` в чистом `QtObject` вне item-tree иногда резолвится, иногда нет (зависит от engine / imports). Надёжнее:

- либо держать scale в root `Main.qml` и передавать вниз,
- либо `import QtQuick.Window` и документировать, что `ThemeState` инстанцируется только из visual root,
- либо сделать `ThemeState` `Item` с `visible: false` / нулевым size.

**Follow-up:** зафиксировать один паттерн в 0.3 и проверить под `qml` / `sddm-greeter-qt6 --test-mode`.
