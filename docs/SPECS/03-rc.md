# Onyx — Detailed Specs: Release Candidate (0.9.x-rc)

**Milestone:** RC  
**Version range:** 0.9.0-rc.1 → 0.9.9-rc  
**Goal:** Packaging, полная документация, QA, подготовка к 1.0.0.

---

## Stage 4.1 — Packaging Final  
**Version:** `0.9.0-rc.1`

### Requirements

1. `PKGBUILD` полностью рабочий (`makepkg -si`).
2. `install.sh` / `uninstall.sh` идемпотентны и безопасны.
3. `onyx-sddm-theme.install` (pacman hooks) с правильными сообщениями.
4. Контрольные суммы (`scripts/checksums.sha256`) актуальны.
5. `verify-theme.sh` проходит 100%.

### Acceptance

- [ ] Чистая установка на свежей CachyOS/Arch.
- [ ] Удаление не оставляет мусора.
- [ ] Тема появляется в `/usr/share/sddm/themes/onyx`.

---

## Stage 4.2 — Documentation Complete  
**Version:** `0.9.0-rc.2`

### Requirements

1. README.md — полная инструкция (установка, настройка, смена темы, troubleshooting).
2. `docs/troubleshooting.md` — все известные проблемы + решения.
3. ARCHITECTURE.md и ROADMAP.md актуальны.
4. PROVENANCE.txt и NOTICE корректны.

### Acceptance

- [ ] Новый пользователь может поставить тему за < 5 минут по README.

---

## Stage 4.3 — CI Completeness  
**Version:** `0.9.0-rc.3`

### Requirements

1. GitHub Actions (или аналог) запускает:
   - syntax check QML
   - validate.sh
   - verify-theme.sh
   - (опционально) screenshot tests
2. Checksums проверяются в CI.

### Acceptance

- [ ] CI зелёный на main.

## Stage 4.5 — Accessibility Pass  
**Version:** `0.9.0-rc.5`

### Requirements

1. Контраст текста ≥ WCAG AA где возможно.
2. Focus visible на интерактивных элементах.
3. Keyboard navigation (Tab / Enter) хотя бы базово работает для password + login.

### Acceptance

- [ ] Можно залогиниться только с клавиатуры.
